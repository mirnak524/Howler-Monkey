# Howler-Monkey
Jungle themed desktop overlay that displays microphone levels with a monkey icon that becomes angrier as you get louder. 

**Highlights**
- Live mic monitoring from the default input device
- Arc meter that lights up with volume to give the user a more accurate depiction of their noise
- 4 different monkey moods
- Adjustable position while snapping to the bottom-right corner of the screen on launch
